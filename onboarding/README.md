# Welcome to MacMediaKeyForwarder Onboarding!

This guide is designed to help you get familiar with the MacMediaKeyForwarder project. We recommend reading through these documents in the order listed below to build a solid understanding of the project and how to contribute.

## Reading Order

1.  **[Project Overview](./1_project_overview.md)**: Understand what MacMediaKeyForwarder does, its main features, and a high-level look at its architecture.
2.  **[Development Environment Setup](./2_development_environment.md)**: Learn how to set up your Xcode environment for this project, including project structure and dependencies.
3.  **[Building and Running the App](./3_building_and_running.md)**: A step-by-step guide to building, running, and debugging the application.
4.  **[Objective-C Basics for This Project](./4_objective_c_basics.md)**: Key Objective-C concepts you'll encounter in this codebase. Essential if you're new to Objective-C.
5.  **[Codebase Introduction](./5_codebase_introduction.md)**: A tour of the important files and directories in the project.
6.  **[Mac App Development Points](./6_mac_app_development_points.md)**: Core macOS development concepts relevant to MacMediaKeyForwarder, including event handling and permissions.
7.  **[Guidance for Future Extensions](./7_future_extensions_guidance.md)**: Some initial thoughts on tackling upcoming features like adding new app support and keyboard simulation.

We hope this guide helps you get up and running quickly. If you have any questions, don't hesitate to ask!
