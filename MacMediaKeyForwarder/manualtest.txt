Start with clean install ( delete app and com.milgra.hmske.plist from ~/Library/Preferences )

Default state :
    - check menu :
        - pause items should be disabled
        - send events to both players should be selected
    - check if app controls Music/Spotify individually and both running.
    - app shouldn't start music players automatically.

Music state :
    - select Prioritize Apple Music from the menu
    - check if app starts up Music automatically
    - check if play/pause/prev/next is working
    - check if fast forward/rewind is working
    - restart app and check if prioritize Apple Music remains selected

Spotify state :
    - select Prioritize Spotify from the menu
    - check if app starts up Spotify automatically
    - check if play/pause/prev/next is working
    - check if fast forward/rewind is working
    - restart app and check if prioritize Spotify remains selected

Pause state :
    - select pause from the menu
    - app shouldn't forward events to player
    - macOS default media key behaviour should happen ( try it with a youtube video in safari )

Auto-Pause state :
    - select pause if no player is running from the menu
    - close Music and Spotify
        - app shouldn't forward events to player
        - macOS default media key behaviour should happen
    - open Music or Spotify
        - app should behave based on the selected priority option

Volume keys to Apple Music :
    - check that "Also send volume keys to Apple Music" is off by default
        - volume keys should only change the system volume
    - turn it on in Settings > Players, play a song in Apple Music
        - volume up/down should change Apple Music's volume by 6 as well as the system volume
        - Shift-Option-volume up/down should change it by 2
        - mute should set Apple Music's volume to 0, mute again should restore it
        - volume up while muted should restore Apple Music's volume and step it
    - quit Apple Music
        - volume keys shouldn't start Apple Music
    - select Prioritize Spotify
        - Apple Music's volume shouldn't change
